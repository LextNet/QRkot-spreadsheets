# приложение QRKot-spreadsheets
Вымышленный благотворительный фонд поддержки котиков QRKot собирает пожертвования на всевозможные задачи, связанные с помощью кошачьей популяции: на корм, на медицинское обслуживание, 
организацию приютов и на другую помощь котам, кошкам и котятам.
Имеется возможность формирования отчёта в Яндекс Диск для QRKot с указанием продолжительности открытия проекта
для сбора средств.

## Установка
1. Клонирование репозитория
git clone https://github.com/LextNet/QRKot-spreadsheets.git
cd QRKot-spreadsheets
2. Настройка переменных окружения и установка необходимых библиотек
pip install -r requirements.txt

## Запуск
(venv) ...$ uvicorn app.main:app
